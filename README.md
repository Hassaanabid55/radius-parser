# Radius Parser

High performance multithreaded RADIUS accounting packet parser built using:

- libpcap
- pthreads
- autotools

## Features

- Live packet capture
- RADIUS Accounting packet filtering
- Multithreaded worker queue
- Session extraction
- IPv4 + UDP parsing
- Attribute parsing
- Modular architecture
